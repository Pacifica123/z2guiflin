# Инструменты приёмки

Единый профиль кандидата: bash meta_tools/hyperpatch_acceptance.sh --p06. Он воспроизводит общий run_step/fail-fast/log/archive workflow и сохраняет полные результаты. Генерация справочника и воспроизводимая сборка проверяются автоматически. Чистая Arch VM требует отдельного lifecycle receipt; container PASS не заменяет сетевую или системную проверку.

Текущая версия 0.10.0rc6 — кандидат P06. Финальное повышение зависит от полного подтверждения поддерживаемой установки, обновления и удаления.
