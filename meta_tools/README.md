# Meta tools

`meta_tools/` содержит инструменты, которые обслуживают сам процесс разработки,
патчей и рабочих областей, но не являются частью runtime/GUI Zap2.

Первый закреплённый инструмент — `meta_tools/devctl/`: исходник и документация
локального конвейера патчей. Обычный `tools/` оставлен под проектные проверки,
экспериментальные утилиты и будущие низкоуровневые инструменты ядра.
