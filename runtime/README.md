# Контракты runtime

Схемы и примеры здесь являются ресурсами пакета. Живые планы, состояния и доказательства находятся в пользовательском workspace. Исторические receipts в p04 фиксируют только прошлую приёмку. Привилегированные операции выполняет package-owned helper с проверкой происхождения. Service unit не устанавливается; lifecycle сервиса остаётся plan-only.

Текущая версия 1.2.0. v1.1 исправила launch diagnostics и Overview; v1.0 закрыта владельцем проекта. Freeze по-прежнему лежит в runtime/v11 — каталог назван по контракту, а не по версии.
