# 2026-10-21-nav-remedies — навигация по пути пользователя и «Что попробовать»

Первый патч пачки A (каркас + витрина). Красная нить — удобство: пользователь не должен заранее знать, какое из средств программы ему нужно.

## Что сделано

- `models/navigation.py`: у секции появилось поле `group`; порядок теперь повторяет путь пользователя:
  Главная, Диагностика → «Средства» (Запуск, Пресеты, Туннель) → «Система» (Ядро, Логи, Настройки).
  Новая секция `home` («Главная»); в этом патче — заглушка, витрину приносит следующий патч.
  Ключи остальных страниц не менялись (на них завязаны Ctrl+K и переходы).
- «Обзор» переименован в «Запуск»: страница запускает/останавливает компоненты, а обзором программы теперь служит «Главная».
- `models/remedy.py` (чистый Python): таблица средств и связь «код вердикта net_verdict → что попробовать».
  У каждого средства — что изменится, нужен ли root, обратимо ли. DPI → «Запуск» и «Пресеты»; IP-блок → «Туннель»;
  DNS → пока совет про nmcli (страница DNS — пачка B); локальная сеть/провайдер — честное «обход тут не поможет».
- `widgets/net_verdict_panel.py`: после вердикта под кнопкой появляется строка «Что попробовать:» с кнопками перехода.
  Переход — через `focus_discovery_target` главного окна; код вердикта читается из JSON-отчёта.
- `windows/main_window.py`: невыбираемые заголовки групп, карта строка списка → страница, последняя страница хранится
  по ключу (`ui/last-page-key`), а не по номеру строки, — порядок можно менять без сюрпризов.
- Иконка `home.svg`, стили заголовков групп в обеих темах и в пользовательском профиле темы.
