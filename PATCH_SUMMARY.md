# 2026-10-21-presets-exclusions-cleanup — общие исключения, читаемые имена Blockcheck, массовое удаление

Шестой патч пачки B, продолжение страницы «Пресеты».

## Что сделано

- **Общие исключения** (`adapters/preset_exclusions.py`, кнопка «Общие исключения…»): домены и IP/CIDR, которые не обрабатывает
  ни один профиль любого пресета (банк, госуслуги, рабочий VPN; «+ локальные сети»). Хранятся в `.zap2/exclusions.json`.
  - Добавляются в единственную точку сборки плана — `execution_plan.materialize_execution_plan`: файлы пресетов не меняются,
    исключения видны в Plan, digest плана меняется вместе с ними.
  - IP/CIDR (`--ipset-exclude-ip`) — во все профили. Домены (`--hostlist-exclude-domains`) — только в профили, где уже есть список
    доменов: по `desync.c` nfqws2 профиль с любым hostlist без имени хоста не выбирается, и исключение домена в IP-профиле сломало бы
    первые пакеты. Окно показывает, сколько профилей выбранного пресета получат домены.
  - Проверка значений: домен из ≥2 меток, `^домен`, CIDR через `ipaddress`; `0.0.0.0/0` отклоняется с объяснением.
  - После сохранения — предложение перезапустить Default (`restart_running_preset`: stop → start тем же пресетом; если не запущен — ничего).
  - Симулятор «Кто сработает первым?» учитывает общие исключения.
- **Читаемые имена Blockcheck**: новые экспорты называются «Сервис: функции стратегии · цель · дата», например
  «YouTube: fake + multisplit · googlevideo.com · 21.10.2026 14:30» (номер добавляется, только если у одной цели несколько вариантов).
  Старые «Blockcheck X / цель #NN» показываются так же (`display_title`), старое название остаётся в поиске.
- **Массовое удаление**: список пресетов с множественным выделением; «Удалить пресеты: N» удаляет свои и найденные Blockcheck
  (`remove_generated_preset` проверяет, что файлы лежат в `strategies/generated` и `presets/generated`), встроенные пропускаются
  с объяснением; если удаляемый выбран — откат на пресет по умолчанию. Меню правой кнопки: «Выделить все найденные Blockcheck»,
  «Удалить выделенные». Ошибки по отдельным пресетам собираются, остальные удаляются.
- `docs/user/presets.md` дополнен.
