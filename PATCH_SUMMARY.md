# Оркестратор стратегий через upstream `circular`

База — патч `2026-10-15-zapret2-106-features` той же пачки, product 1.1.0.

Добавлен оркестрированный тип профиля поверх upstream-оркестратора `circular` из `core/zapret2/lua/zapret-auto.lua`. GUI не перебирает стратегии сам: он собирает 2..N кандидатов с автоматическими тегами `strategy=N`, необязательным `final` на последней и параметрами fails/time/nld/reqhost/key, а некорректный ввод отклоняет с русским текстом ошибки. Синтаксис взят из `zapret-auto.lua` (`function circular`) и manual: экземпляр `circular` стоит перед `--payload`, входящий захват `--in-range=-s5556` включается только для него (детектору провала нужны входящие RST, ретрансмиссии и HTTP-редиректы), а `zapret-auto.lua` подключается в `--lua-init` автоматически.

Кандидаты берутся из профилей strategies/*.json: структурированного хранилища успешных результатов Blockcheck пока нет. В конструкторе пресетов появился режим «Оркестратор (circular, эксперимент)». Debug-лог nfqws2 разбирается в записи {host, from, to, reason} по точным строкам из Lua. Пример `orchestrated-circular-example` (experimental) зарегистрирован в каталоге и shipping allowlist. Ожидаемые счётчики пресетов в тестах обновлены: 18→19 пресетов, 64→65 профилей. Документ `docs/user/orchestrator.md` поясняет, что одно переключение не делает стратегию устойчивой.

Доска: карточка в «Сделано»; добавлена «Приёмка: circular на реальном трафике». v1.1 source freeze пересчитан.
