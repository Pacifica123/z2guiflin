# Сгенерированные пресеты

В этот каталог Blockcheck exporter записывает текстовые `.txt` пресеты рядом с metadata сгенерированной стратегии.

Файл появляется только после явного экспорта результата со статусом `AVAILABLE`. Сам экспорт не запускает preset и не меняет runtime. Владелец должен отдельно проверить содержимое, выбрать стратегию, подготовить Default workflow plan и подтвердить запуск.
