# Встроенный snapshot strat_collection

Этот каталог содержит исходный набор стратегий strat_collection как справочные данные для z2guiflin. Файл `strag.json` используется для построения нативного каталога в GUI. Файлы `.bat` относятся к Windows `winws.exe`/zapret1 и читаются только как текст: z2guiflin их не запускает, не вызывает WinDivert и не выполняет команды `taskkill`/`sc`.

Цель интеграции — сохранить метаданные, hostlist/ipset и fake-ресурсы, показать используемые `--dpi-desync-*` параметры и упростить поиск идей для ручного порта в Zapret2/nfqws2. Автоматическая конвертация в Lua-стратегии намеренно не выполняется, потому что соответствие между zapret1 и zapret2 не является механическим и требует проверки конкретной стратегии.
