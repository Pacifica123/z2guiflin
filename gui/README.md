# Графический интерфейс

GUI использует PyQt6 и неизменяемый код установленного пакета. Поиск и помощь читают канонические ActionContract. About показывает независимые версии продукта, upstream, core, схем и evidence. Writable state находится в пользовательском workspace; запуск не требует ручного PYTHONPATH.

Текущая версия 1.0.0rc7 — кандидат P07. Финальное повышение зависит от полного подтверждения поддерживаемой установки, обновления и удаления.
