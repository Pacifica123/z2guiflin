# Графический интерфейс

GUI использует PyQt6 и неизменяемый код установленного пакета. Поиск и помощь читают канонические ActionContract. About показывает независимые версии продукта, upstream, core, схем и evidence. Writable state находится в пользовательском workspace; запуск не требует ручного PYTHONPATH.

Текущая версия 1.5.0: GoogleVideo Discovery (P1), опциональный CDP-сбор при просмотре YouTube (P2). В 1.4.0 добавлены профили Discord и YouTube, проверка вложений Discord, иконки сервисов и DNS. 1.3.0 — DNS, удобные пресеты, Tor с мостами, автообновление. 1.2.0 — навигация по пути пользователя и витрина на «Главной». v1.1 исправила launch diagnostics и Overview; v1.0 закрыта владельцем проекта.
