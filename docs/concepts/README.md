# Понятия и границы результатов

Контекст запуска хранит выбранные настройки. Пресет задаёт рецепт обработки пакетов, а traffic profile — упорядоченный фильтр внутри рецепта. Не выбирайте случайный пресет по одному симптому: сначала определите слой и минимальное изменение, затем проверьте свежее соединение.

Plan описывает эффект и входные ресурсы, имеет стабильный hash и не является выполнением. Confirmation связывает согласие с конкретным планом; изменение его входов требует нового подтверждения. Run — отдельное исполнение; Evidence — наблюдения с ID, временем, входами и областью применимости. Capability требует всех mandatory predicates.

Работа процесса или локального SOCKS не доказывает удалённый TLS, HTTPS, Discord Gateway или окно Vesktop. UNKNOWN нельзя повышать до PASS. Снимок состояния после изменения запуска надо обновить. Localhost сам по себе не гарантирует приватность.

Package-owned файлы принадлежат пакетному менеджеру. Пользовательский compatibility workspace содержит управляемые копии ресурсов, user-owned пресеты и `.zap2` state. Это разные ownership boundaries: пользовательские файлы не удаляются при pacman uninstall, а изменённые managed copies не перезаписываются молча при обновлении.
