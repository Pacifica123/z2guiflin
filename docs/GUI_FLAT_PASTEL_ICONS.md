# GUI flat pastel icons

Дата: 2026-06-29

## Цель

Сделать интерфейс менее мрачным, не отходя от flat-подхода:

- плоские минималистичные иконки;
- мягкие пастельные тона;
- одна иконка = mono/duotone, без 3D;
- понятные символы для основных разделов и действий;
- табличный GUI остаётся читаемым и копируемым.

## Что добавлено

Иконки лежат в `gui/zap2_gui/assets/icons/` и подключаются через `gui/zap2_gui/ui_icons.py`.

Покрытие:

- верхние вкладки: Overview, Core, Strategies, Diagnostics, Tunnel, Settings, Logs;
- под-вкладки страницы Logs;
- основные кнопки в Overview: start/stop, refresh, Discord probe, logs, copy table, copy last output.

## Визуальный принцип

Каждая иконка состоит из:

- мягкой pastel background формы;
- простого тёмного flat glyph;
- без теней, градиентов и псевдо-объёма.

## Почему так

Текущий GUI уже стал более полезным функционально, но по тону был слишком чёрно-серым. Эти иконки не меняют workflow, но делают разделы и действия заметнее без визуального шума.
