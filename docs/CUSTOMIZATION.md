# Настройка интерфейса и быстрый выбор пресетов

## Быстрая замена пресета

На вкладке «Пресеты» включён режим «Применять пресет одним кликом». Если Default выключен, клик только меняет выбранный preset. Если Default уже работает, один клик выполняет транзакцию `stop текущего -> смена selection -> start нового`. Для privileged stop/start используется существующий графический `sudo -A/SUDO_ASKPASS`; после истечения sudo-сессии запрос пароля может появиться снова.

Если остановить старый runtime не удалось, selection не меняется. Если новый preset не запустился, z2guiflin возвращает предыдущий selection и делает одну попытку восстановить предыдущий runtime. Результат и rollback выводятся в панели деталей. Режим можно отключить в «Настройки -> Пресеты»; кнопка «Применить пресет» остаётся явным ручным действием.

## Поиск пресетов

`Ctrl+F` переводит фокус в строку поиска на вкладке «Пресеты». Фильтр применяется сразу, без отдельной кнопки. Он работает и для локальных Zapret2 presets, и для встроенного каталога strat_collection. Эта UX-модель перенесена из проекта-вдохновителя loop-uh: при большом наборе presets поиск быстрее прокрутки списка.

## Создание собственной темы

Откройте «Настройки -> Оформление». Сначала выберите светлую или тёмную основу, затем измените семантические цвета, шрифт, размер шрифта, скругление и ширину панели навигации. Кнопка «Применить» сразу применяет профиль и сохраняет его через QSettings. Ширина навигации также меняется без перезапуска.

Для переноса темы нажмите «Экспорт темы…». Полученный JSON можно изменить вручную и импортировать кнопкой «Импорт темы…». Пример находится в `themes/example-custom.json`. Формат имеет `schemaVersion: 1`; цвета задаются строго как `#RRGGBB`. Помимо базовых ролей доступны отдельные роли `noticeBg/noticeBorder/noticeText/noticeBadge/noticeBadgeText` для верхних runtime-уведомлений и `statusRunning/statusStopped/statusWarning/statusUnknown` для плоского индикатора состояния. Старые theme-файлы schema v1 без этих ключей остаются валидными: отсутствующие роли берутся из выбранной светлой/тёмной основы. Неизвестные цветовые ключи игнорируются, некорректные значения отклоняются. Поля `font.sizePt`, `metrics.cornerRadiusPx` и `metrics.navigationWidthPx` имеют безопасные диапазоны и нормализуются при загрузке.

Тема меняет только Qt palette/QSS и геометрию панели навигации. Она не изменяет nftables, NFQUEUE, systemd, runtime plans или sudo-policy.

## strat_collection

Snapshot strat_collection встроен в `presets/collections/strat_collection` и отображается отдельной вкладкой внутри «Пресеты». `strag.json` используется как нативный индекс: доступны название, provider, label, порты, host lists, desync modes, исходные winws-аргументы и проверка ссылок на companion `.txt/.bin/.dat`.

Коллекция исторически содержит Windows `.bat` для `winws.exe`/zapret1. z2guiflin читает их только как текст: BAT, `taskkill`, `sc`, WinDivert и `winws.exe` никогда не исполняются.

Кнопка над вкладками контекстная. На вкладке strat_collection она показывает один из трёх режимов: `Портировать + применить`, `Применить порт` или `Автопорт недоступен`. Автопорт разрешён только тогда, когда каждый legacy-параметр выбранной записи имеет явное соответствие в vendored Zapret2. Windows capture flags отбрасываются, создаётся обычный owner-managed preset, после чего используется тот же транзакционный hot-swap, что и для остальных Zapret2 presets. Исходная запись коллекции не изменяется.

Если встречается неоднозначный legacy mode (`split`, `split2`, `disorder`, `disorder2` и т.п.), неизвестный fake payload, неподдержанный `dup/wssize` или отсутствующий companion-файл, кнопка блокируется и детали показывают точную причину. z2guiflin не угадывает соответствие. Это позволяет использовать автоматически переносимую часть коллекции, не выдавая приблизительную конверсию за эквивалентную стратегию.
