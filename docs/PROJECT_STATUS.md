# Фактический статус проекта

Текущий кандидат P06: **0.10.0rc6 / v0.10 RC6**. Он не повышен до финальной версии: полный lifecycle на чистой Arch VM требует отдельного owner receipt. Последний независимо зафиксированный финальный продукт — **0.8.0**: P04 закрыт (P04a, P04b, P04c, P04d), marker `READY_FOR_USE_WITHIN_P04D`. Вход P06 — предоставленный post-P05 snapshot `ca6b4fb`; отдельная новая owner-приёмка P05 в архиве отсутствует. Это граница доказательств, а не повторное закрытие предыдущих этапов.

P06 реализует разделение current/history, генерируемый справочник, воспроизводимый source release, локальный PKGBUILD, desktop launcher, package-owned helper, отдельный пользовательский workspace с receipt и сохранением данных при обновлении/удалении. About показывает независимые идентификаторы. Support bundle использует положительный список полей и не экспортирует raw logs, VLESS URI или конфигурации.

Сервисный lifecycle: plan-only, unit не устанавливается и не включается. Выполнение действий по-прежнему проходит через 119 канонических ActionContract; 117 legacy selectors сохраняют closure. Сетевые verdict не повышаются по версии продукта и требуют доказательств текущего запуска.

Приёмка кандидата включает полный регрессионный корпус без исключения real-process тестов. Контейнер с несовпадающими PID и `/proc` блокирует соответствующие проверки; это не PASS. Чистая Arch VM install→launch→inspect/plan→owned start/stop→diagnostics→upgrade→support→uninstall является обязательным отдельным receipt для финального повышения до 0.10.0.

Историческая опора P03: `READY_FOR_USE_WITHIN_P03`, закреплённый upstream 1.0.6. Этот marker относится к прежней owner-приёмке и не закрывает новую чистую VM установку P06.
