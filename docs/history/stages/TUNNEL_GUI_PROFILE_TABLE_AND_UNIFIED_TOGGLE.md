# Таблица tunnel-профилей и общий переключатель в обзоре

Дата: 2026-06-29

## Почему

Во вкладке `Туннель` после добавления core-start блока элементы стали тесными: импорт, core, route и output оказались в одной вертикальной куче. Это ломало UX.

Также главная кнопка в `Обзоре` запускала только Default/Zapret workflow, хотя рядом уже был блок выбора компонентов. Поэтому статус мог показывать `Запущен`, когда Zapret работает, но VLESS tunnel не запущен.

## Что изменено

### Tunnel tab

Вкладка `Туннель` теперь разделена на три под-вкладки:

- `Профили VLESS`;
- `Tunnel core`;
- `Discord через SOCKS`.

`Профили VLESS` показывают импортированные подключения таблицей, по аналогии со стратегиями. Сырые `vless://` строки не показываются.

Таблица содержит:

- active marker;
- remarks;
- redacted destination;
- transport;
- security;
- host override;
- connection id.

Для выбора profile больше не нужно читать текстовый лог: выбирается строка таблицы и нажимается `Сделать активным`.

### Overview

Главная кнопка запуска теперь работает по выбранным компонентам в блоке `Комбинированный запуск`.

Если выбраны `Zapret default + VLESS tunnel`, то индикатор `Всё запущено` появляется только когда оба supported-компонента реально running.

Если один из выбранных компонентов stopped/failed/not ready, статус показывает, что не все выбранные компоненты running.

## Ограничения

VLESS tunnel всё ещё требует core binary. GUI не скачивает core автоматически и не подменяет несовместимый VLESS transport.
