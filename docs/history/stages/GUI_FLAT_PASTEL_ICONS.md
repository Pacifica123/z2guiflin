# Плоские минималистичные иконки GUI

Дата: 2026-06-29

## Цель

Сделать интерфейс менее тяжёлым, но не добавлять визуальный шум.

Новая версия иконок использует:

- line-icon стиль;
- без цветных квадратных подложек;
- без 3D, теней и псевдо-объёма;
- без мелких внутренних деталей;
- один спокойный пастельный цвет на иконку;
- близкую плотность к Windows GUI reference: маленький символ рядом с текстом, а не отдельная декоративная картинка.

## Покрытие

Иконки лежат в `gui/zap2_gui/assets/icons/` и подключаются через `gui/zap2_gui/ui_icons.py`.

Покрыты:

- верхние вкладки: Overview, Core, Strategies, Diagnostics, Tunnel, Settings, Logs;
- под-вкладки Logs;
- основные Overview-действия: start/stop, refresh, Discord probe, logs, copy table, copy last output.

## Важное исправление

Кнопка запуска больше не смешивает старый текстовый символ `▶/■` с новой SVG-иконкой. Теперь она icon-only, а текстовое состояние живёт рядом в status pill.
