# История, ADR и предыдущие этапы

Материалы `stages/` сохраняют исходные байты документации до P06. `migration-index.json` фиксирует прежний путь, новый путь и SHA-256. Числа версий, experimental recipes и statements внутри отражают время соответствующего документа; они не являются текущими инструкциями по установке или поддержке.

Старые пути оставлены как явно подписанные redirects. Проверки исторических решений читают перенесённый оригинал; current-help строится из текущих contracts и не использует stage docs по умолчанию. Прежние frozen runtime receipts также не переписываются.
