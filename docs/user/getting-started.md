# Установка и первые действия на Arch, Manjaro и EndeavourOS

Поддерживаемый путь P06 — локальный пакет `zap2gui-linux` из воспроизводимого release-архива и сгенерированного PKGBUILD. Версия продукта — кандидат **1.0.0rc7**, следующий final release назначается после приёмки. Wheel/pip без полного resource bundle не считается поддерживаемой установкой.

## Установка

Получите проверенные release `.tar.gz` и PKGBUILD вместе. Поместите их в один пустой каталог. В обычной пользовательской сессии выполните `makepkg -si`: makepkg сверит SHA-256 исходного архива, а pacman установит системные файлы. GUI требует Python ≥ 3.10 и PyQt6. Для сборки nfqws2 отдельно нужны native build dependencies, которые приложение проверит до исполнения.

После установки запустите `zap2-gui` из меню приложений или терминала. Не нужны checkout, ручной PYTHONPATH или копирование кода в домашний каталог для импорта. Системный launcher импортирует только package-owned Python-код. При первом запуске он создаёт пользовательский compatibility workspace в `$XDG_DATA_HOME/zap2gui/workspace` (по умолчанию `~/.local/share/zap2gui/workspace`). Там находятся runtime, редактируемые пресеты и результаты сборки; системное resource tree не изменяется.

## Первое безопасное действие

Нажмите Ctrl+K и найдите `default.workflow.status` или выполните `zap2-gui --action default.workflow.status`. Просмотр не доказывает доступность внешней сети. Для запуска сначала выберите пресет, проверьте файлы и зависимости, подготовьте план, изучите его эффект, затем подтвердите и выполните через штатный workflow. Если ядро ещё не собрано, подготовьте и выполните build plan; приложение собирает проверенную staged generation в пользовательском workspace.

Root-helper установлен пакетом в `/usr/lib/zap2gui/zap2-runtime-executor`. Он выполняет только ограниченные типы запросов и никогда не импортирует Python из workspace. GUI не запускают через sudo; повышение прав запрашивается только для конкретного действия. Если helper не прошёл ownership/mode/hash check, переустановите пакет через pacman; не устанавливайте пользовательскую копию helper с sudo.
