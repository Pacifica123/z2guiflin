# Установка и первые действия на Arch, Manjaro и EndeavourOS

Текущая версия **1.3.0**. Есть два штатных пути: запуск собственного checkout и установка пакета. Wheel/pip без resource bundle не заменяет системный пакет.

## Из исходников

Откройте корень проекта и выполните `bash ./run.sh`. Терминал может быть zsh, но сам run.sh требует Bash. GUI не запускайте через sudo. Требуются Python ≥ 3.10 и PyQt6; установите `sudo pacman -S --needed python python-pyqt6` при их отсутствии. Checkout использует свою .zap2; переход к установленному пакету не импортирует её автоматически.

## Пакет для автора проекта

Готовый release извне не нужен. Из корня checkout выполните:

```bash
sudo pacman -S --needed base-devel python python-pyqt6
bash meta_tools/build_local_package.sh
cd dist/arch/1.3.0
makepkg -si
```

Скрипт создаёт соответствующие archive и PKGBUILD; makepkg запускается в **dist/arch/1.3.0**, а не в произвольном каталоге. SHA подтверждает, что рецепт собирает именно созданный архив. Сокращённый workflow: `bash meta_tools/build_local_package.sh --install`. makepkg работает от обычного пользователя и сам вызывает pacman для установки. Полученный у другого пользователя archive+PKGBUILD также должны лежать вместе; makepkg выполняют в содержащем их каталоге.

После установки запустите `zap2-gui` из меню приложений или терминала. Не нужны checkout, ручной PYTHONPATH или копирование кода в домашний каталог для импорта. Системный launcher импортирует только package-owned Python-код. При первом запуске он создаёт пользовательский compatibility workspace в `$XDG_DATA_HOME/zap2gui/workspace` (по умолчанию `~/.local/share/zap2gui/workspace`). Там находятся runtime, редактируемые пресеты и результаты сборки; системное resource tree не изменяется.

## Первое безопасное действие

Нажмите Ctrl+K и найдите `default.workflow.status` или выполните `zap2-gui --action default.workflow.status`. Просмотр не доказывает доступность внешней сети. Для запуска сначала выберите пресет, проверьте файлы и зависимости, подготовьте план, изучите его эффект, затем подтвердите и выполните через штатный workflow. Если ядро ещё не собрано или receipt устарел, нажмите «Собрать ядро» прямо в Overview, просмотрите подробности плана и подтвердите сборку; приложение собирает проверенную staged generation в пользовательском workspace.

Root-helper установлен пакетом в `/usr/lib/zap2gui/zap2-runtime-executor`. Он выполняет только ограниченные типы запросов и никогда не импортирует Python из workspace. GUI не запускают через sudo; повышение прав запрашивается только для конкретного действия. Если helper не прошёл ownership/mode/hash check, переустановите пакет через pacman; не устанавливайте пользовательскую копию helper с sudo.
