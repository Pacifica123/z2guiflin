# Версионирование продукта и доказательств

Текущий кандидат P06: **0.10.0rc6 / v0.10 RC6**. Он не повышен до финальной версии: полный lifecycle на чистой Arch VM требует отдельного owner receipt. Последний независимо зафиксированный финальный продукт — **0.8.0**: P04 закрыт (P04a, P04b, P04c, P04d), marker `READY_FOR_USE_WITHIN_P04D`. Вход P06 — предоставленный post-P05 snapshot `ca6b4fb`; отдельная новая owner-приёмка P05 в архиве отсутствует. Это граница доказательств, а не повторное закрытие предыдущих этапов.

Номинальный шаг P06 по плану — 0.9→0.10. До полного подтверждения lifecycle используется 0.10.0rc6. Версия продукта находится в pyproject и модуле пакета; она не является версией vendored upstream, внешнего core, schema или evidence. About и генерируемый JSON перечисляют эти оси раздельно. Замороженные исторические receipts не переписываются при смене версии или расположения документации.

0.10.0 допускается только после успешной детерминированной приёмки и отдельной чистой VM проверки, включая установленный launcher, владение helper, настоящее обновление и удаление с сохранением пользовательских данных. Повторная установка того же release не считается проверкой перехода между версиями.

Историческая ступень v0.7 соответствовала закрытию foundation до финального перехода P04d→0.8.0; её receipts остаются в истории и не меняют текущую кандидатную версию.
