# Язык и актуальность документации

Активная проектная документация пишется на русском языке. Названия внешних протоколов, кодовых идентификаторов, контрактов и команд сохраняются для точности. Каждый этап обновляет текущие инструкции и статус. Исторические оригиналы сохраняются побайтно; новые переходы объясняют их временной контекст. Генерируемый справочник обновляется из исполняемых источников и проверяется автоматически, без ручного исправления дублирующего реестра.

Vendored upstream в `core/zapret2` сохраняет собственный язык и лицензии. Эти файлы не переводятся механически и не становятся текущей локальной инструкцией; происхождение фиксируется отдельным import manifest.
