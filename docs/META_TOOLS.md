# Meta tools

`meta_tools/` — отдельная зона для инструментов, которые обслуживают разработку,
патчи, рабочие области и выпускные процедуры. Они не являются частью GUI/runtime
слоя Zap2 GUI Linux и не должны импортироваться приложением.

## devctl

`meta_tools/devctl/` содержит локальный снимок `devctl`: исходник `devctl.py`,
`install.sh` и документацию формата devctl-compatible zip-патча. Смысл снимка —
не заменить внешний рабочий wrapper, а держать рядом с проектом проверяемый
reference: какой `manifest.json` ожидается, как устроен `files/`, какие поля
проверяет `devctl plan/start` и почему патчи надо отдавать именно в этом формате.

## Граница с tools

`tools/` оставлен под проектные read-only проверки и будущие технические утилиты
самого Zap2 GUI Linux. Поэтому текущие проверки лежат в `tools/gui_checks/`, а
`tools/experimental/` и `tools/lowlevel/` зарезервированы под будущие прототипы и
низкоуровневые packet/parser utilities.
